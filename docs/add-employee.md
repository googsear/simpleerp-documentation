
# How to Add a New Employee

## Purpose

This procedure explains how to add a new employee to the SimpleERP system.

## Prerequisites

- You must have access to SimpleERP.
- You must have permission to manage employee records.

## Procedure

1. Log in to SimpleERP.
2. Navigate to **Human Resources**.
3. Select **Employee Management**.
4. Click **Add Employee**.
5. Enter the employee details:

   **Mandatory fields:**
   - Employee Name *
   - Employee ID *
   - Department *

   **Optional fields:**
   - Designation
   - Date of Joining
   - Email Address
6. Click **Save**.

## Expected Result

The system saves the employee record and displays a success message.
